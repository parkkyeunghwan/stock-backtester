주식 전략 백테스터

CSV를 올리면 이평선 등 여러 전략을 수익률·MDD·승률로 비교하고, 파라미터를 바꿔가며 차트로 확인합니다.

날짜·시가·고가·저가·종가·거래량 열이 있는 일봉 CSV (영문/한글 헤더 모두 가능). 신호 발생 다음날 시가에 체결합니다.
분석 기간 비워 두면 전체 기간 · 데이터를 불러오면 적용 기간이 표시됩니다.
기본은 전체 기간이며, 백테스트·차트 / 전략 탐색 / 현재 신호 / 폴더 스캔에 공통 적용됩니다. 이평선·RSI는 시작일 이전 데이터까지 포함해 계산하고 매매만 시작일부터 반영합니다(시작일 직전 이미 매수 상태면 시작일 시가 진입, 종료일 보유분은 종료일 종가로 평가). 현재 신호 상태는 항상 마지막 데이터 기준이고, 전략 선정과 과거 수익률은 선택 기간 기준입니다. 폴더 스캔은 종목별로 데이터가 있는 구간만 쓰며 버튼을 눌러야 다시 실행됩니다.

▲ 빨강=매수, ▼ 파랑=매도, 옅은 빨강 배경=전략이 보유 중인 구간, 매수·매도 지점 점선으로 연결된 글씨=해당 지점의 날짜와 체결가(신호 다음날 시가)(‘매수구간 색칠’ 버튼으로 끄고 켤 수 있음). 아래는 전략 vs 단순 보유 자산 곡선, 그리고 전략 낙폭(MDD). 휠=확대/축소(마우스 위치 기준), 드래그=좌우 이동, 더블클릭=전체 보기, 모바일은 핀치·한 손가락 드래그, 차트를 클릭하면 크게 보기(ESC로 닫기). 세 차트는 같은 구간으로 함께 움직입니다.
추세선: ✏ 직접 그리기를 켜고 주가 차트를 드래그하면 선이 그려지고(휠 확대는 그대로 가능), 그리기 모드에서 선을 클릭하면 삭제됩니다. 직접 그은 선은 종목별로 이 브라우저에 저장됩니다. 자동 추세선·회귀 채널은 현재 화면에 보이는 구간 기준이므로, 분석하려는 구간으로 확대한 뒤 눌러 주세요. 참고용 도구이며 투자 권유가 아닙니다.
이평선 크로스·종가/이평·정배열·돌파·RSI 조합을 전부 돌립니다. 행을 누르면 차트로 이동. 저장해 둔 내 전략 1·2·3이 있으면 표 맨 위에 ★ 주황색 줄로, 그 바로 아래에 단순보유 줄이 항상 고정되어 표시됩니다(정렬을 바꿔도 움직이지 않으며, 순위·점수는 전체 탐색 결과와 비교한 값). 평균 보유 열은 선택 기간 거래의 평균 보유 거래일수로, 20일 이하는 단기(주황) · 120일 이하는 중기(초록) · 그보다 길면 장기(보라)로 칸 배경색이 달라집니다(열 제목을 누르면 보유가 짧은/긴 순으로 정렬). 오른쪽 끝 A / B 버튼은 전략 혼합 탭에 쓸 전략을 지정합니다.

기간 종합: 모든 전략을 분석 기간 종료일 기준 최근 1년·3년·5년·전체 구간에서 각각 평가해 연환산 수익률(CAGR) 순위의 평균으로 종합점수(0~100)를 매깁니다. 데이터가 모자란 기간은 건너뜁니다. 최악기간은 그중 가장 나쁜 구간의 CAGR, 롤링승률은 1년 창을 한 달씩 밀며 단순보유를 이긴 비율입니다. 이웃안정(0~100)은 같은 전략에서 파라미터를 한 칸씩 바꾼 이웃 전략들의 종합점수 평균과 최저값의 평균을 구한 뒤, 자신의 종합점수를 넘지 않게 제한한 값입니다. 이웃들이 함께 좋아야 높게 나오므로, 점수만 높고 이웃이 나쁜 ‘뾰족한 우연’을 걸러냅니다(셀에 마우스를 올리면 이웃 수·평균·최저가 보입니다). 최소 거래수는 전체 구간 기준이고, 선택기간 수익·MDD·승률·거래 열은 선택한 분석 기간 기준입니다. 한 기간에서만 좋은 전략은 종합점수·최악기간·롤링승률이 낮게 나옵니다. 현재 상태는 항상 마지막 데이터 기준이며, 매수자리(최근 3거래일 안에 매수 신호 발생)·보유 유지(그보다 오래 매수 상태)·매도자리(최근 3거래일 안에 매도 신호 발생)·관망(매수 조건 미충족) 중 하나입니다. 상태에 마우스를 올리면 신호 발생 시점이 보입니다.

폴더 안의 CSV를 모두 읽어 종목별로 전략 탐색과 현재 신호 판정을 실행합니다. 정렬 기준과 최소 거래수는 전략 탐색 탭 설정을 따르고, 수수료·손절 설정과 위의 분석 기간도 그대로 적용됩니다. 폴더 선택은 PC 크롬/엣지에서 동작하고, 폰에서는 “CSV 여러 개 선택”으로 파일을 한꺼번에 고르세요(종목 수가 많으면 시간이 오래 걸립니다).
전략 탐색(최적화) 결과를 순위 순서대로 보여 줍니다. 순위는 전략 탐색 탭의 정렬 기준을 따르고, 행을 누르면 차트로 이동합니다.

각 연도(1/1~12/31)의 전략 수익률입니다. 위에서 설정한 분석 기간 안의 구간만 계산하며, 첫 해·마지막 해가 연중 일부이면 연도 옆에 *를 붙입니다(그 해는 일부 기간 수익률). 맨 위 줄은 같은 기간의 단순보유 수익률이고, 그 아래 주황색 ★ 줄은 이 종목에 저장해 둔 내 전략 1·2·3(저장 당시 손절 설정 기준)이며, 전략이 단순보유보다 높은 연도는 굵게 표시합니다.

머리글(순위·전략·파라미터·각 열·연도)을 누르면 그 열 기준으로 정렬되고, 다시 누르면 오름/내림차순이 바뀝니다. 정렬은 표시 중인 순위 목록 안에서 이루어지며, 단순보유·★ 저장 전략 줄은 맨 위에 고정됩니다. 값이 없는 칸(-)은 항상 아래로 갑니다.

랜덤 3년 열은 전략 혼합 탭과 같은 방식입니다: 전체 데이터에서 무작위로 뽑은 N년 구간 여러 개의 평균수익률을 여러 번 반복해 다시 평균낸 값이며(연수·구간 수·반복 횟수는 전략 혼합 탭의 설정을 따르고, 구간은 분석 기간과 무관하게 모든 전략에 똑같이 적용), 🎲 버튼으로 구간을 다시 뽑으면 이 탭에도 반영됩니다.

평균은 연도별 수익률의 산술평균, 편차(σ)는 연도별 수익률의 표준편차(표본), 최저는 가장 나빴던 해의 수익률입니다. 연중 일부인 첫 해·마지막 해(*)는 제외하고 계산하며(온전한 해가 2개 미만이면 전부 포함), 편차가 작을수록 해마다 고르게 번 전략입니다. 1위 상관은 표에 나온 모든 전략의 일별 수익률이 1위 전략과 얼마나 같이 움직였는지(−1~1)이고, 현재 전략 상관은 지금 백테스트 탭에서 실행 중인 전략과의 상관입니다. 수치는 순위와 상관없이 모두 표시되지만, 상관이 가장 낮은 전략을 추천하는 보라색(1위 기준)·청록색(현재 전략 기준) 표시는 순위 1~20위 안에서만 고릅니다(실행 중인 전략이 1~20위 안에 있으면 자기 자신은 제외). 1위와 다르게 움직이는 전략이라 섞으면 해마다의 편차를 줄여줄 가능성이 있습니다(전략 혼합 탭에서 확인).

폴더 스캔으로 나온 종목들끼리 수익률의 피어슨 상관계수를 계산합니다(스캔 때 적용된 분석 기간 기준, 두 종목이 모두 거래된 날짜만 사용). 빨강 높을수록 같이 움직임(분산 효과 낮음), 파랑 낮거나 음수일수록 따로 움직임. 먼저 폴더 스캔 탭에서 스캔을 실행하세요. 현재 백테스트 중인 종목은 맨 위 카드와 행렬에서 ▶ 표시로 강조되고, 정렬 기본값은 ‘현재 종목 기준’입니다.

폴더 스캔으로 나온 종목을 칸으로 그린 지도입니다. 칸 크기는 거래대금(종가×거래량), 색은 빨강=상승·파랑=하락입니다. 업종 정보가 CSV에 없어서 스캔한 폴더 안의 하위 폴더를 업종처럼 묶습니다(예: 폴더 안에 ‘양극재’, ‘전해액’ 폴더를 나눠 두면 업종별로 표시). 코스피·코스닥은 따로 그리며, 폴더 이름에 ‘코스피’ 또는 ‘코스닥’(영문 KOSPI/KOSDAQ도 가능)이 들어 있을 때만 자동으로 나눕니다(예: 코스닥/양극재/에코프로.csv). 파일 이름에 들어 있는 코스닥·코스피는 종목명으로만 취급하며, 해당 폴더가 없는 종목은 ‘미분류’ 지도에 따로 표시됩니다. 색 진하기 기준은 비워 두면 1일 ±5%, 5일 ±10%, 20일 ±20%, 분석기간 ±50%입니다. 칸을 누르면 그 종목의 현재 신호 탭으로 이동합니다. 수익률은 스캔 때 적용된 분석 기간의 마지막 날 기준입니다.

전략 탐색과 같은 후보 전체를 대상으로, 훈련 구간 성과만 보고 전략 1개를 고른 뒤 그 뒤의 검증 구간에서 어떻게 됐는지를 구간을 밀어가며 확인합니다(미래 데이터는 선정에 쓰지 않습니다). 롤링은 [훈련 N년 → 검증 M년]을 M년씩 밀고, 단일 분할은 분석 기간을 비율로 앞·뒤로 나눕니다. 이웃 안정성 반영을 켜면 훈련 성과가 아니라 ‘이웃 전략 평균과 최저를 함께 고려한 값’으로 고르므로 파라미터 우연에 덜 민감합니다. 후보 내 백분위는 검증 구간에서 고른 전략이 같은 후보 전체 중 어느 위치였는지(100=1등, 50=중간)로, 평균이 50 근처면 훈련 성과로 고르는 방식에 예측력이 없다는 뜻입니다. 수수료·세금·손절·거래량 필터 설정과 분석 기간이 그대로 적용됩니다.

전략 탐색(최적화) 결과에서 두 전략을 골라 자금을 비중대로 나눠 각각 독립적으로 운용했을 때의 합산 결과입니다. 전략 탐색 탭 표의 A / B 버튼으로도 지정할 수 있습니다. 비중 재조정은 분기(1·4·7·10월 첫 거래일) 또는 연 1회(첫 거래일)에 비중을 되돌립니다. 재조정 시 자금 이동 비용은 반영하지 않습니다.
저장 전략 A·B·C 2조합 전부 버튼은 저장한 전략 3개 중 2개씩(A+B, A+C, B+C) 모든 조합을 같은 설정으로 계산합니다. 이때 “A 비중”은 각 조합에서 앞 전략(A+C이면 A, B+C이면 B)의 비중입니다. 전략 A/B 선택을 바꾸면 다시 2전략 혼합 화면으로 돌아옵니다.
