IO Switcher Web

브라우저에서 BLE 장치를 검색하고 GATT 서비스를 확인·읽기·쓰기하는 웹 클라이언트

1. 장치 연결

연결되지 않음
아직 선택한 장치가 없습니다.

Chrome 또는 Edge 최신 버전에서 사용하세요. Bluetooth 연결은 HTTPS 또는 localhost에서만 동작합니다.

2. 서비스 및 특성 탐색

연결 후 검색할 수 있습니다.

연결 후 장치가 제공하는 GATT 서비스가 표시됩니다.

3. IO Switcher 전원 제어

제어 방식채널 1 + 채널 2 연동 반전 설정활성화 제어 특성000015ba-0000-1000-8000-00805f9b34fb

장치를 연결하고 제어 특성을 검색하면 사용할 수 있습니다.

반전 활성화: ON 버튼은 OFF 키(채널 1·2), OFF 버튼은 ON 키(채널 1·2)를 전송합니다. 명령 전송 완료는 실제 전원 상태 확인과 다릅니다.

4. 선택한 특성 제어

속성-UUID-

5. 동작 기록

웹 클라이언트 준비 완료.\n
주의: ON/OFF 명령은 업로드된 기존 Windows 프로그램에서 확인한 키 값에 맞춰 구성했습니다. 실제 장치에서 최초 테스트할 때는 스위치 부하와 주변 안전을 확인하세요.

브라우저 호환성 및 현재 한계

  • Windows PC의 Chrome/Edge에서 Web Bluetooth 사용을 권장합니다.
  • iPhone/iPad의 Safari는 Web Bluetooth를 지원하지 않습니다.
  • 웹 페이지는 브라우저가 허용한 GATT 서비스만 접근할 수 있습니다. 장치 서비스 UUID가 확인되면 접근 목록을 정확히 지정해야 합니다.
  • 기존 프로그램과 동일한 IO 버튼 동작을 완성하려면 실제 장치의 서비스 UUID, 특성 UUID, ON/OFF 명령 규칙 확인이 필요합니다.
